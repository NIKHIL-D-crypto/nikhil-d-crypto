Case 02

Phylab

A physics lab companion for Kerala Polytechnic students.

  • HTML
  • CSS
  • JavaScript
  • PWA

Live ↗Code ↗

The problem

Lab work depends on careful readings and the right calculations. Phylab guides students through each Engineering Physics experiment: what to do, what to read and exactly how to calculate.

What it does

  • Virtual experiments
  • Observation recording
  • Graphs
  • Lab records
  • A "Fill sample data" button that shows a full worked run
  • Light and dark theme

How it's built

Plain HTML, CSS and JavaScript. It is a progressive web app with a manifest and a service worker, so it can work offline.
