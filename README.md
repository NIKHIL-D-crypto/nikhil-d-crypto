# NIKHIL K | Portfolio

Developer portfolio: a home page plus a case study for each featured project (Campus Cash, Phylab, Sonora, Panam).

Live: https://nikhil-d-crypto.github.io/nikhil-portfolio/

## How it's built

- Plain HTML, CSS and JavaScript. No build step and no dependencies.
- Light and dark themes follow the device, with a manual toggle (`assets/script.js`, the only script).
- Fonts (Space Grotesk and Inter) are self-hosted in `assets/` under the SIL Open Font License; see `assets/font-licenses.txt`.
- Hosted on GitHub Pages.

## Structure

- `index.html`: home page
- `case-*.html`: one case study per project
- `assets/`: stylesheet, script, favicon and fonts

## Editing content

Open a page, find the comment that starts with `EDIT:`, change the text below it and commit. The header and footer are repeated on each page, so change them on every page.
