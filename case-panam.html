Case 04

Panam

A simple, local-first money tracker for adults.

  • HTML
  • CSS
  • JavaScript

Live ↗Code ↗

The problem

Panam and Campus Cash solve the same problem for different people. Campus Cash is expressive and animated for students; Panam is simple and easy to use for adults.

What it does

  • Cash, bank/UPI and savings tracked separately
  • Budgets with monthly history
  • Backup files, CSV export and duplicate-skipping import
  • Imports Campus Cash backups
  • Backup reminders
  • Accessibility options such as larger text and high contrast

How it's built

Plain HTML, CSS and JavaScript, hosted on GitHub Pages. Data lives only in the browser.
