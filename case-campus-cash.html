Case 01

Campus Cash

A money manager built for students.

  • HTML
  • CSS
  • JavaScript

Live ↗Code ↗

The problem

Students need a simple way to see where their money goes. Campus Cash makes that visible without an account or sign-up. Its sibling, Panam, solves the same problem for adults with a simpler interface.

What it does

  • Expense and income tracking
  • Budgets
  • Interactive dashboards and analytics
  • Monthly recap
  • Backup and CSV export
  • No account needed; data stays in the browser

How it's built

Plain HTML, CSS and JavaScript, hosted on GitHub Pages. Data is stored in the browser, so there is no server or account.
